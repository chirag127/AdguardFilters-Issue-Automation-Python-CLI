filter-report

Multi-platform ad/tracker/cookie-popup/annoyance filter report preparer. Pre-fills issue templates for uBlock, AdGuard, EasyList, Brave, and more — then opens them for 1-click human submit.

Get started View on GitHub

Why semi-automatic, not headless?

Every major filter-list project — uBlock, AdGuard, EasyList, Brave — explicitly requires human reporters. Automated bot submissions lead to bans and revoked access. filter-report does the tedious work (correct template, formatted title/body, URL construction) and leaves the actual Submit click to you. That 1-click is intentional — it is the only policy-compliant design.

8 platforms, 1 command

Prepare reports for uBlock, AdGuard, EasyList, Brave, DandelionSprout, Peter Lowe, ph00lt0 simultaneously.

Pre-filled templates

Each platform gets the right issue format — title, body, checkboxes, selector — no copy-paste.

Zero credentials

No GitHub token. No API calls. Pure URL construction with query-param pre-fill. Works offline.

Rule generator

Generate adblock-syntax rules (||domain^, ##.selector) to add to your own lists instantly.

Install

pip install filter-report

Requires Python 3.9+. Dependencies: click, requests.

Usage

Prepare reports (opens in browser)

# cookie popup on example.com — uBlock + AdGuard (default)
filter-report prepare https://example.com --category cookie-popup

# ad — three platforms
filter-report prepare https://example.com -c ad -p uassets,adguard,easylist

# with CSS selector, print URLs without opening browser
filter-report prepare https://example.com -c tracker \
  --selector "#tracker-pixel" \
  --no-browser

List platforms

filter-report platforms

Generate an adblock rule

filter-report rule ads.example.com
# => ||ads.example.com^

filter-report rule banner.example.com --type hide

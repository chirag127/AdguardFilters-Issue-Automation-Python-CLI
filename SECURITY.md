## Reporting a Vulnerability

We take all security bugs in this project seriously. If you find a security issue, please report it to us by email at [security@example.com](mailto:security@example.com).

We'll respond to your report within 48 hours, and we'll do our best to fix the issue as quickly as possible.

Please do not report security vulnerabilities through public GitHub issues.

We may award a bounty for security bugs, depending on the severity of the issue.
